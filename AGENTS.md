# AGENTS.md — Cocoon (web)

## What this is
A React web app, Cocoon. Animated, data-driven UI with sound. See `PLAN.md` for the current build plan.

> Note: this is the **web** Cocoon, distinct from the iOS "Cocoon" app in `~/becoming 3`.

## Tech stack
- React 18 + Vite
- Tailwind CSS (+ PostCSS)
- framer-motion (animation)
- recharts (charts)
- tone.js (audio)
- lucide-react (icons)

## Layout
- `src/` — components (JSX)
- `PLAN.md` — build plan / roadmap
- `tailwind.config.js`, `postcss.config.js`, `vite.config.js` — tooling
- `index.html` — Vite entry

## Run
`npm install` then `npm run dev`.
